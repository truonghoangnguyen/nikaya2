# 11. Rāgapeyyāla

1\. “Rāgassa, bhikkhave, abhiññāya satta dhammā bhāvetabbā. Katame satta? Satisambojjhaṅgo …pe… upekkhāsambojjhaṅgo— rāgassa, bhikkhave, abhiññāya ime satta dhammā bhāvetabbā”ti.

1\. “Rāgassa, bhikkhave, abhiññāya satta dhammā bhāvetabbā. Katame satta? Aniccasaññā, anattasaññā, asubhasaññā, ādīnavasaññā, pahānasaññā, virāgasaññā, nirodhasaññā— rāgassa, bhikkhave, abhiññāya ime satta dhammā bhāvetabbā”ti.

1\. “Rāgassa, bhikkhave, abhiññāya satta dhammā bhāvetabbā. Katame satta? Asubhasaññā, maraṇasaññā, āhāre paṭikūlasaññā, sabbaloke anabhiratasaññā, aniccasaññā, anicce dukkhasaññā, dukkhe anattasaññā— rāgassa, bhikkhave, abhiññāya ime satta dhammā bhāvetabbā”ti.
