# PLI-TV-BU-VB-SK 2. Dutiyaparimaṇḍalasikkhāpada

## Sekhiyakaṇḍa

# 2. Dutiyaparimaṇḍalasikkhāpada

1.1\. Tena samayena buddho bhagavā sāvatthiyaṁ viharati jetavane anāthapiṇḍikassa ārāme. Tena kho pana samayena chabbaggiyā bhikkhū puratopi pacchatopi olambentā pārupanti …pe….

1.3\. “Parimaṇḍalaṁ pārupissāmīti sikkhā karaṇīyā”ti.

1.4\. Parimaṇḍalaṁ pārupitabbaṁ ubho kaṇṇe samaṁ katvā. Yo anādariyaṁ paṭicca purato vā pacchato vā olambento pārupati, āpatti dukkaṭassa.

1.6\. Anāpatti— asañcicca, assatiyā, ajānantassa, gilānassa, āpadāsu, ummattakassa, ādikammikassāti.

1.14\. Dutiyasikkhāpadaṁ niṭṭhitaṁ.
