# PLI-TV-BU-VB-SK 3. Suppaṭicchannasikkhāpada

## Sekhiyakaṇḍa

# 3. Suppaṭicchannasikkhāpada

1.1\. Tena samayena buddho bhagavā sāvatthiyaṁ viharati jetavane anāthapiṇḍikassa ārāme. Tena kho pana samayena chabbaggiyā bhikkhū kāyaṁ vivaritvā antaraghare gacchanti …pe….

1.3\. “Suppaṭicchanno antaraghare gamissāmīti sikkhā karaṇīyā”ti.

1.4\. Suppaṭicchannena antaraghare gantabbaṁ. Yo anādariyaṁ paṭicca kāyaṁ vivaritvā antaraghare gacchati, āpatti dukkaṭassa.

1.6\. Anāpatti— asañcicca, assatiyā, ajānantassa, gilānassa, āpadāsu, ummattakassa, ādikammikassāti.

1.14\. Tatiyasikkhāpadaṁ niṭṭhitaṁ.
