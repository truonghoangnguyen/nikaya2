# MIL 7.5.3. Opammakathāpañha

0\. Upacikāvagga

## 3. Undūraṅgapañha

1\. “Bhante nāgasena, ‘undūrassa ekaṁ aṅgaṁ gahetabban’ti yaṁ vadesi, katamaṁ taṁ ekaṁ aṅgaṁ gahetabban”ti? “Yathā, mahārāja, undūro itocito ca vicaranto āhārūpāsīsako yeva carati; evameva kho, mahārāja, yoginā yogāvacarena itocito ca vicarantena yoniso manasikārūpāsīsakeneva bhavitabbaṁ. Idaṁ, mahārāja, undūrassa ekaṁ aṅgaṁ gahetabbaṁ. Bhāsitampetaṁ, mahārāja, therena upasenena vaṅgantaputtena—

2\.
> ‘Dhammāsīsaṁ karitvāna,\
> viharanto vipassako;\
> Anolīno viharati,\
> upasanto sadā sato’”ti.

3\. Undūraṅgapañho tatiyo.
