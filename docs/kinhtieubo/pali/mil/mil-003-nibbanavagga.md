# MIL 3. Nibbānavagga

## 9. Nibbānalabhanapañha

1\. Rājā āha—“bhante nāgasena, sabbeva labhanti nibbānan”ti? “Na kho, mahārāja, sabbeva labhanti nibbānaṁ, api ca kho, mahārāja, yo sammā paṭipanno abhiññeyye dhamme abhijānāti, pariññeyye dhamme parijānāti, pahātabbe dhamme pajahati, bhāvetabbe dhamme bhāveti, sacchikātabbe dhamme sacchikaroti, so labhati nibbānan”ti.

2\. “Kallosi, bhante nāgasenā”ti.

3\. Nibbānalabhanapañho navamo.
