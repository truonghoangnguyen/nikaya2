# MIL 3.3.13. Vicāravagga

## 13. Vitakkalakkhaṇapañha

1\. “Bhante nāgasena, kiṁlakkhaṇo vitakko”ti? “Appanālakkhaṇo, mahārāja, vitakko”ti.

2\. “Opammaṁ karohī”ti. “Yathā, mahārāja, vaḍḍhakī suparikammakataṁ dāruṁ sandhismiṁ appeti; evameva kho, mahārāja, appanālakkhaṇo vitakko”ti.

3\. “Kallosi, bhante nāgasenā”ti.

4\. Vitakkalakkhaṇapañho terasamo.
