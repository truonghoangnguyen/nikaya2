# MIL 7.7.2. Opammakathāpañha

0\. Makkaṭakavagga

## 2. Thanassitadārakaṅgapañha

1\. “Bhante nāgasena, ‘thanassitadārakassa ekaṁ aṅgaṁ gahetabban’ti yaṁ vadesi, katamaṁ taṁ ekaṁ aṅgaṁ gahetabban”ti? “Yathā, mahārāja, thanassitadārako sadatthe laggati, khīratthiko rodati; evameva kho, mahārāja, yoginā yogāvacarena sadatthe laggitabbaṁ, sabbattha dhammañāṇena bhavitabbaṁ, uddese paripucchāya sammappayoge paviveke garusaṁvāse kalyāṇamittasevane. Idaṁ, mahārāja, thanassitadārakassa ekaṁ aṅgaṁ gahetabbaṁ. Bhāsitampetaṁ, mahārāja, bhagavatā devātidevena dīghanikāyavare parinibbānasuttante—

2\. ‘Iṅgha tumhe, ānanda, sāratthe ghaṭatha, sāratthe anuyuñjatha, sāratthe appamattā ātāpino pahitattā viharathā’”ti.

3\. Thanassitadārakaṅgapañho dutiyo.
