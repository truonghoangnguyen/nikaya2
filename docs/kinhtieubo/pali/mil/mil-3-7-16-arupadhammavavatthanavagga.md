# MIL 3.7.16. Arūpadhammavavatthānavagga

## 16. Arūpadhammavavatthānadukkarapañha

1\. Rājā āha—“bhante nāgasena, dukkaraṁ nu kho bhagavatā katan”ti? Thero āha—“dukkaraṁ, mahārāja, bhagavatā katan”ti. “Kiṁ pana, bhante nāgasena, bhagavatā dukkaraṁ katan”ti. “Dukkaraṁ, mahārāja, bhagavatā kataṁ imesaṁ arūpīnaṁ cittacetasikānaṁ dhammānaṁ ekārammaṇe vattamānānaṁ vavatthānaṁ akkhātaṁ ‘ayaṁ phasso, ayaṁ vedanā, ayaṁ saññā, ayaṁ cetanā, idaṁ cittan’”ti.

2\. “Opammaṁ karohī”ti. “Yathā, mahārāja, kocideva puriso nāvāya mahāsamuddaṁ ajjhogāhetvā hatthapuṭena udakaṁ gahetvā jivhāya sāyitvā jāneyya nu kho, mahārāja, so puriso ‘idaṁ gaṅgāya udakaṁ, idaṁ yamunāya udakaṁ, idaṁ aciravatiyā udakaṁ, idaṁ sarabhuyā udakaṁ, idaṁ mahiyā udakan’”ti? “Dukkaraṁ, bhante, jānitun”ti. “Ito dukkarataraṁ kho, mahārāja, bhagavatā kataṁ imesaṁ arūpīnaṁ cittacetasikānaṁ dhammānaṁ ekārammaṇe vattamānānaṁ vavatthānaṁ akkhātaṁ ‘ayaṁ phasso, ayaṁ vedanā, ayaṁ saññā, ayaṁ cetanā, idaṁ cittan’”ti. “Suṭṭhu, bhante”ti rājā abbhānumodīti.

3\. Arūpadhammavavatthānadukkarapañho soḷasamo.

4\. Arūpadhammavavatthānavaggo sattamo.

5\. Imasmiṁ vagge soḷasa pañhā.
