# MIL 3.3.14. Vicāravagga

## 14. Vicāralakkhaṇapañha

1\. “Bhante nāgasena, kiṁlakkhaṇo vicāro”ti? “Anumajjanalakkhaṇo, mahārāja, vicāro”ti.

2\. “Opammaṁ karohī”ti. “Yathā, mahārāja, kaṁsathālaṁ ākoṭitaṁ pacchā anuravati anusandahati, yathā, mahārāja, ākoṭanā, evaṁ vitakko daṭṭhabbo. Yathā anuravanā, evaṁ vicāro daṭṭhabbo”ti.

3\. “Kallosi, bhante nāgasenā”ti.

4\. Vicāralakkhaṇapañho cuddasamo.

5\. Vicāravaggo tatiyo.

6\. Imasmiṁ vagge cuddasa pañhā.
