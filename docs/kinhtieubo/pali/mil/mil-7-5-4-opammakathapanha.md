# MIL 7.5.4. Opammakathāpañha

0\. Upacikāvagga

## 4. Vicchikaṅgapañha

1\. “Bhante nāgasena, ‘vicchikassa ekaṁ aṅgaṁ gahetabban’ti yaṁ vadesi, katamaṁ taṁ ekaṁ aṅgaṁ gahetabban”ti? “Yathā, mahārāja, vicchiko naṅgulāvudho naṅgulaṁ ussāpetvā carati; evameva kho, mahārāja, yoginā yogāvacarena ñāṇāvudhena bhavitabbaṁ, ñāṇaṁ ussāpetvā viharitabbaṁ. Idaṁ, mahārāja, vicchikassa ekaṁ aṅgaṁ gahetabbaṁ. Bhāsitampetaṁ, mahārāja, therena upasenena vaṅgantaputtena—

2\.
> ‘Ñāṇakhaggaṁ gahetvāna,\
> viharanto vipassako;\
> Parimuccati sabbabhayā,\
> duppasaho ca so bhave’”ti.

3\. Vicchikaṅgapañho catuttho.
